Measured entitlement value

What each subscription delivered at public API prices, under the workload actually observed. Every estimate is drawn with the evidence behind it: the band is the 80% slope range, the fill is how much of the window had recorded spend beside it.

Value per full weekly entitlement

Short windows are converted to weekly terms using the ratio measured from their own quota movement, so every series sits on one axis.

Value over time

One point per reset window, placed where its evidence ends. A step between settled points is a change in what the entitlement delivered — which is how a provider quietly moving an allowance becomes visible, and datable. The open window is drawn hollow: it is still accumulating, so movement there is convergence, not change.

Independent measurements

Two windows of one account, or two accounts on one plan, measure the same thing. Disagreement means either an assumption here is wrong or something changed at the provider.
